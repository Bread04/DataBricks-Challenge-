## Run 1 · toolkit standards (2026-09-21): Backend standards and stack

Full report: [`technical-hackathon-toolkit-2026-09-21/research.md`](../../_research/technical-hackathon-toolkit-2026-09-21/research.md)

- **Errors:** RFC 9457 (2023-07) obsoletes RFC 7807. It uses `application/problem+json` with `type`, `title`, `status`, `detail` and `instance`, plus extensions such as an `errors[]` array with JSON pointers. Don't leak internals [T21][T27].
- **Free tiers:**
  - Supabase: 2 projects, 500 MB DB, **pauses after 1 week idle**, 50k MAU [T22].
  - Clerk Hobby: 50k **MRU**, 7-day fixed sessions [T23].
- **Auth:**
  - Clerk + Supabase now uses Supabase Third-Party Auth: a `role: authenticated` claim plus supabase-js `accessToken()`. The JWT template has been deprecated since 2025-04-01 [T24][T25].
  - On Next.js 16 `clerkMiddleware()` lives in `proxy.ts` [T26]. Next.js warns never to rely on proxy alone for authorization [T27].
- **Data access:** Next.js recommends a server-only Data Access Layer returning DTOs. Treat Server Actions as public endpoints and re-check auth in each one. Rate-limit Route Handlers with 429 [T27][T28].
- **RLS:** write one policy per operation, scope it `to authenticated`, use `(select auth.uid())`, and index the policy columns [T29]. Supabase plans to make default table grants opt-in (**no date given**); opting in now is recommended [T30]. Its sample rate limiter returns a non-standard 420 [T30].
- **Migrations:** `migration new` → `db diff` → `db reset` → `db push`; never edit the remote database directly [T31].
- **Security baseline:** the OWASP API Top 10 2023 is still the latest edition [T32].
- **API style:** REST, GraphQL or tRPC guidance comes only from blogs [T33] (low confidence). By inference from [T27][T28]: Server Components + DAL for reads, Server Actions for mutations, REST only for webhooks.

## Run 1 · toolkit standards (2026-09-21): Web3 (ETHGlobal-style)

Full report: [`technical-hackathon-toolkit-2026-09-21/research.md`](../../_research/technical-hackathon-toolkit-2026-09-21/research.md)

*Deepen 2026-09-22.*

- **Starting point:** `npx create-eth@latest` (Scaffold-ETH 2) wires up Next.js, wagmi, viem and RainbowKit, and lets you choose Foundry or Hardhat [T75]. The repo was pushed 2026-08 [T101].
- **Toolchain:** Hardhat 3 is stable, and Nomic claims it covers most of Foundry's functionality, including Solidity tests and fuzzing [T74] (a vendor claim). Foundry (10.6k stars) and Hardhat (8.5k) are both active [T101]. No source recommending one over the other was found, so use whichever the team knows.
- **Wallets:** WalletConnect is now **Reown**, and Web3Modal is now **Reown AppKit** [T78]. RainbowKit was last pushed 2026-05 [T101]. Coinbase Smart Wallet is branded Base Account (secondary source). EIP-7702 has been live on mainnet since Pectra (2025-05-07) [T76].
- **Networks:** Holesky has been sunset. Use Sepolia for apps and Hoodi for validators [T76]. Base Sepolia faucets (CDP, Alchemy) give 0.1 ETH per 24 h [T77].
- **Onboarding:** Privy has a free tier, but its MAU cap is disputed (499 vs 1,000) [T102].
- **Security:** start from OpenZeppelin Contracts (27.2k stars) and its Wizard [T101]. Deploy to testnets only.

## Run 1 · toolkit standards (2026-09-21): App deployment beyond Vercel and Railway

Full report: [`technical-hackathon-toolkit-2026-09-21/research.md`](../../_research/technical-hackathon-toolkit-2026-09-21/research.md)

*Deepen 2026-09-22.*

- **Render Free:** sleeps after 15 min idle and takes about 1 min to wake. It gives 750 instance-hours a month, and free Postgres expires after 30 days [T92].
- **Railway:** a one-time $5 trial, then a $1/mo Free plan (0.5 GB RAM). A card is now required [T93].
- **Fly.io:** a trial only, lasting 2 machine-hours or 7 days [T94] (medium confidence).
- **Cloudflare Workers Free:** 100K requests/day and 10 ms CPU per request [T95].
- **Netlify:** 300 credits a month, and each production deploy costs 15 credits [T96].
- **Hugging Face Spaces:** Gradio and Docker Spaces now need PRO. Free accounts older than 30 days get up to 2 ZeroGPU Gradio Spaces, and static Spaces stay free [T97].
- **Streamlit Community Cloud:** apps sleep after 12 h without traffic [T98].
- **Modal:** $30/mo of free compute [T99].
- **Demo-day implication:** open every free-tier URL 5–10 minutes before presenting.

## Run 2 · GitHub repos (2026-09-22): Backend and infra

Full report: [`technical-hackathon-github-repos-2026-09-21/research.md`](../../_research/technical-hackathon-github-repos-2026-09-21/research.md)

- **BaaS:** Supabase 110k, PocketBase 61k, Appwrite 57k, Convex self-host 12k; headless CMS: Strapi 73k, Payload 44k (Figma-owned [G11]), Directus 37k [G1].
- **Auth:** Better Auth (30k) now maintains Auth.js, which gets only security and urgent fixes [G7]. Lucia is deprecated [G5]. Keycloak, Zitadel, Logto and SuperTokens are active [G1].
- **ORMs:** Drizzle is overtaking Prisma for new projects [G23] (medium confidence). Prisma's repo is now `prisma/orm` [G1]. Turso is a beta Rust rewrite of SQLite; libSQL is the stable option [G24].
- **APIs:** FastAPI 102k, NestJS 76k, Express 69k, tRPC 40k, Fastify 37k, Hono 32k [G1]. Hono's npm growth reportedly rivals Fastify [G25].
- **Frameworks:** RedwoodJS is now RedwoodGraphQL in maintenance mode [G26]. sahat/hackathon-starter (35k) is active [G1]. create-t3-app and nextjs/saas-starter were last pushed 2025-12 [G1].
- **Deploy and tunnels:** Coolify 62k, Dokploy 37k, Dokku 32k [G1]. localtunnel is stale; frp (109k) and cloudflared are active [G1][G27].
- **API clients:** Postman now requires login; Bruno and Hoppscotch are MIT alternatives [G28].

## Run 3 · agents & fullstack practices (2026-09-23): Backend practices

Full report: [`technical-agents-and-fullstack-practices-2026-09-23/research.md`](../../_research/technical-agents-and-fullstack-practices-2026-09-23/research.md)

**Currency check against the current cheat sheet:**

| Cheat-sheet item | Verdict |
| --- | --- |
| Next.js 16 / `proxy.ts` | ✅ current. Now **16.3.x; pin ≥ 16.3.6**. GHSA-vcvr-r3jv-pc5j / CVE-2026-94545 (CVSS 9.5) affects the Node `ImageResponse` in `>=16.2.0 <16.3.6` when user input reaches the SVG. Edge is unaffected [A71][A72][A73]. 15.x: use 15.5.26 [A73]. Multiple critical advisories in the past year [A70] |
| Cache model | "Cache Components" + `use cache` is the 16.x model. 16.3 adds Instant Navigations and `catchError`/`retry()` [A70] |
| Supabase RLS | ⚠️ **changed.** Tables also need an explicit `GRANT` to `anon`, `authenticated` and `service_role`. Default for new projects from 2026-05-30, all projects from **2026-10-30**. Otherwise you get "permission denied for table" [A74] |
| Supabase keys | ⚠️ **changed.** `anon`/`service_role` are deprecated "by end of 2026". Use `sb_publishable_…` / `sb_secret_…`. The env var is now `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` [A75][A76] |
| `getClaims()` | ✅ still the recommended server check [A76] |
| Clerk via Third-Party Auth | ✅ recommended. The JWT template has been deprecated since 2025-04-01 [A77] |
| Free tiers | Supabase: 2 projects, 500 MB, 50k MAU, pauses after 1 week [A78]. Clerk: 50k MRU, **no MFA/passkeys** [A79] |
| Upstash | ⚠️ free tier is **500K commands per month** (not per day), 256 MB [A92] |
| Zod | ✅ v4 (4.6.5) [A96] |
| OWASP API Top 10 2023 | ✅ still the latest API edition. The 2025 list is the separate web-app Top 10 (medium confidence) |

**Missing practices worth adding:**

- **Env validation:** `@t3-oss/env-nextjs`. Import it in `next.config.ts` so a missing variable fails the build instead of production [A91].
- **Serverless Postgres:** use the Supabase transaction pooler on :6543 with prepared statements disabled. Direct :5432 connections are IPv6 [A80].
- **Background jobs:** Vercel Workflows (GA 2026-04-16; Hobby includes 50k events/month and keeps run state for 1 day) [A86][A87]. Inngest is free for 50k executions [A89]. Trigger.dev v4 has a $5 credit [A90]. Vercel Queues is still beta, so avoid it [A88].
- **Auth alternatives:** Better Auth, which Vercel acquired on 2026-07-07 (still MIT) [A81][A82], now maintains Auth.js and tells new projects to use Better Auth [A83].
- **ORM:** Prisma 7 dropped the Rust engine, so the old "heavy on serverless" advice is outdated [A84].
- **Email:** Resend's free tier has a **100 emails/day** cap [A93].
- **Alternatives:** Neon (100 CU-hours, 0.5 GB per project) [A94]. Convex (1M function calls/month; medium confidence) [A95].
- **Python path:** `uv add "fastapi[standard]"` + `fastapi dev`. FastAPI is at 0.141.1 [A85].

Not researched: webhook signature verification, Supabase signed upload URLs, Stripe sandboxes, Firebase/Cloudflare free tiers, CORS (see open questions).
