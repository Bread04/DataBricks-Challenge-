## Run 1 · toolkit standards (2026-09-21): Frontend standards and tooling

Full report: [`technical-hackathon-toolkit-2026-09-21/research.md`](../../_research/technical-hackathon-toolkit-2026-09-21/research.md)

- **Performance:** Core Web Vitals "good" is LCP ≤ 2.5 s, INP ≤ 200 ms, CLS ≤ 0.1 at p75 [T8]. No 2025–26 change was found (medium confidence). JS budgets rest on a 2018 heuristic: about 170 KB compressed critical path and Lighthouse ≥ 80 [T9] (low confidence, stale).
- **Accessibility:** WCAG 2.2 has been a Recommendation since 2024-12. It asks for 4.5:1 text contrast, 3:1 for UI components, visible focus that isn't fully obscured, and targets of at least 24×24 CSS px [T10][T11]. WCAG 3 is still a Working Draft (2026-09-10), with a final version expected no earlier than about 2028 [T12] (medium confidence).
- **Tokens:** the DTCG spec reached its first stable version, 2025.10 [T13]. Tailwind v4 `@theme` emits variables and utilities, and a single `--spacing` base drives the scale [T14]. Atlassian's 8 px spacing scale is 0–80 px [T15].
- **Anti-slop tooling:**
  - Impeccable is 1 skill with 24 commands and 61 deterministic detector rules, built on Anthropic's frontend-design skill [T16][T17].
  - Blogs cite older figures (18 skills, 23 commands, 58 rules). The README wins.
- **Tools:**
  - Stitch was relaunched on 2026-05-19 with an agent canvas. Official exports go to Antigravity and Netlify [T18]; Figma is reached through a plugin (low–medium confidence).
  - 21st AI generates shadcn/React variants via MCP or CLI, on a daily free allowance [T19].
  - shadcn changes monthly: Base UI became the default primitive layer in Jul 2026, and it has had an MCP server since Aug 2025 [T20].

## Run 1 · toolkit standards (2026-09-21): Mobile

Full report: [`technical-hackathon-toolkit-2026-09-21/research.md`](../../_research/technical-hackathon-toolkit-2026-09-21/research.md)

*Deepen 2026-09-22.*

- **Expo:** SDK 57 is stable (React Native 0.86, React 19.2), and SDK 58 went to beta on 2026-09-15 [T79]. React Native has run only on the New Architecture since 0.82 [T82].
- **Getting it onto judges' phones:**
  - Expo Go for SDK 57 was still awaiting App Store approval on iOS as of 2026-08-13 [T79].
  - EAS Free gives 15 Android + 15 iOS builds a month (low-priority queue) and EAS Update to 1K MAUs [T80].
  - An Android APK can be installed directly. iOS ad hoc distribution needs UDIDs and a paid account, capped at 100 devices [T81].
- **UI:** NativeWind v5 is pre-release, so use v4 [T83]. React Native Reusables (8.7k stars), gluestack-ui, Tamagui (14.2k) and HeroUI Native (3.7k) are all active [T101].
- **Auth:** `@clerk/clerk-expo` is deprecated in favour of `@clerk/expo`. Its native components need a development build [T84].

## Run 2 · GitHub repos (2026-09-22): Frontend UI

Full report: [`technical-hackathon-github-repos-2026-09-21/research.md`](../../_research/technical-hackathon-github-repos-2026-09-21/research.md)

- **Components:** shadcn/ui (124k) leads, with ant-design and MUI (~99k each), DaisyUI, Chakra (v3 on Ark UI), Mantine and HeroUI (30.8k) [G1]. shadcn/ui switched its default primitives to Base UI in Jul 2026 [G10]. NextUI is now HeroUI v3 on React Aria + Tailwind v4 [G8]. Origin UI is now coss ui [G17].
- **Wow factor:** React Bits was 2025's top-rising UI project (+32.8k stars; #2 overall behind n8n) [G15]; Magic UI has 22k stars [G1]. GSAP is reportedly fully free after the Webflow acquisition [G18] (medium confidence). lottie-web is stale, so use dotLottie [G1].
- **Charts:** Chart.js ranked #1 in State of JS 2025 "other tools" [G19]. Recharts is described as "the most practical default" [G20]. Tremor went to Vercel (components now free) but was last pushed 2025-10 [G1][G21].
- **Canvas, editors, flows:** tldraw (50k) needs a production license key [G22]; xyflow, Tiptap and BlockNote are all active [G1].
- **Design-to-code:** screenshot-to-code (79k), Onlook, Dyad and bolt.diy are active [G1][G15].

## Run 3 · agents & fullstack practices (2026-09-23): Frontend practices

Full report: [`technical-agents-and-fullstack-practices-2026-09-23/research.md`](../../_research/technical-agents-and-fullstack-practices-2026-09-23/research.md)

**Currency check:**

| Cheat-sheet item | Verdict |
| --- | --- |
| Tailwind v4 `@theme` | ✅ v4.3.3, no v5 [A98]. Tailwind Labs joined Shopify 2026-09-09. It stays MIT and "nothing changes"; Tailwind Plus and ui.sh are closed to new sign-ups [A97] |
| shadcn: Base UI default (Jul 2026) | ✅ Radix is still supported [A99]. ⚠️ The CLI is **v4** with `--base`, not 3.x [A100]. React Aria is now a third option. Chat components (Jun), Human-in-the-Loop AI SDK helpers (Aug), and `cn` in its own package (Sep) [A101] |
| Next.js / React Compiler | 16.3 (2026-08-03). The React Compiler is stable but opt-in. `next dev` writes an `AGENTS.md` for coding agents [A70] |
| Impeccable | ✅ `npx impeccable install`, 24 commands, a no-LLM detector CLI, Apache-2.0 [A103] |
| Anthropic frontend-design skill | ✅ still present. Make deliberate, brief-specific choices and avoid AI-default clusters [A123] |
| Stitch MCP | ✅ an official Google codelab exists (API key, Antigravity MCP store) [A113]. The `npx @google/stitch-mcp` command comes from blogs only (low confidence) |
| WCAG 2.2 / Core Web Vitals | not re-checked this run. They're stable standards verified in the 2026-09-21 run |

**Missing practices worth adding:**

- **AI-feature UI.**
  - Libraries: AI SDK UI (`useChat`, generative UI mapping tool results to components) [A105], **AI Elements** (shadcn-based conversation, streaming, tool-call and reasoning components) [A104], and shadcn's own chat and approval helpers [A101].
  - AG-UI / CopilotKit are for a backend running a separate agent framework [A106].
  - Make streaming states, tool-call progress cards, approval prompts, and error or empty states explicit requirements.
- **2026 defaults** (npm-verified): TanStack Query 5.103 [A116], Zustand 5.0 [A117], React Hook Form 7.88 + resolvers 5.9 [A118], TanStack Form 1.33 stable [A119], Motion 13.4 [A114]. Zod v4 support in the form libraries is inferred, not verified.
- **Motion accessibility:** use `<MotionConfig reducedMotion="user">` [A115]. Same-document View Transitions are Baseline. Cross-document ones don't work in Firefox [A107].
- **Accessibility test:** `@axe-core/playwright` 4.13 in a smoke test [A120]. Lighthouse CI hasn't had a release since 2025-06, so it's stale [A121].
- **The EAA** covers commercial products and services such as e-commerce and banking [A122]. Microenterprises providing services are exempt (law-firm summary). Hackathon prototypes are practically out of scope (inference).
- **AI app-builder free tiers are tight** (vendor pages, medium confidence), so spread your prompts across tools and teammates' accounts:
  - v0: $5/month plus 7 messages a day [A108]
  - Lovable: 5 credits a day, 30 a month [A109]
  - Bolt: 300K tokens a day [A110]
  - Figma: 500 AI credits a month, and one Make generation can use 100+ [A111]
  - 21st.dev Hobby: 2 copies a day, with AI features from $15 a month [A112]
- **Judges:** one working flow, clean rather than elaborate [A69]. A single-reviewer post says elaborate UI makes judges "wonder where the backend time went" [A124] (low confidence).
