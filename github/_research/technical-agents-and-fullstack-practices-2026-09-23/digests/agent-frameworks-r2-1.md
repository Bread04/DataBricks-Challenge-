## Matrix verdict
The tentative matrix mostly holds, with some refinements:
- **TS: AI SDK v7 or Mastra holds.** AI SDK v7 has a first-class `ToolLoopAgent` with a default 20-step cap (#1–2), a stable MCP client (#5) and a tool-approval setting (#3). Mastra has full MCP client and server support (#7) and a mostly Apache-2.0 license (#6). **Caveat for beginners:** most tutorials online predate v7. Renames (#3), plus Node 22 and ESM-only (#4), will break copy-pasted v5/v6 code. The guide should include a short "v6 names → v7 names" cheat sheet and a Node 22 check. Mastra's `ee/` features are not free for production (#6), which doesn't matter at a hackathon but is worth a footnote. Whether Mastra is built on the AI SDK is still medium confidence (#8).
- **Python: Pydantic AI was not re-checked this round** (budget), so the claim stands on round 1 evidence only. LangChain v1 `create_agent` is a credible alternative: a single factory on the LangGraph runtime (#13) with built-in MCP (#12). Sentiment is still split, though (#17 vs #18), so keep LangChain/LangGraph as "only if you already know it".
- **Fastest path: a plain provider-SDK loop holds and is well supported.** Anthropic lists the Client SDK tool loop (or tool runner) as its own option (#14), and HN practitioners in 2026 favor framework-free or own-client builds (#17, #19).
- **Add a row: "Agent that edits files or runs code" → Claude Agent SDK** (#14), or OpenAI Agents SDK Sandbox Agents in TS (#16). Managed Agents costs about $0.08/hr plus tokens (#15), which is affordable for a hackathon, but it needs an API key and credits, and there's no free tier beyond the small starter credits.
- MCP works across all the checked frameworks (AI SDK, Mastra, CrewAI, MS Agent Framework, LangChain), so MCP support doesn't separate them (#5, #7, #9, #10, #12).

## Notes for synthesis
- Update anything in the guide that points to `langchain-mcp-adapters`: from LangChain v1.4 the docs point to the built-in `MCPAdapter` (#12). Needs a second source before it's stated firmly.
- AI SDK `needsApproval` is deprecated but still present in v7, so older approval examples may still run while `toolApproval` is the current way (#3).
- MCP sampling is deprecated at the spec level (#11). Don't teach it.
- Old complaint "LangChain abstraction overhead": v1 narrows the surface area to `create_agent` plus middleware (#13), but Sept 2026 HN comments still call it bloated or unnecessary (#17). Treat the complaint as only partly addressed. The evidence is anecdotal on both sides.
- None of the sentiment comes from engineering-blog retrospectives. It's all HN comments; see the gaps below.
