## Notes for synthesis
- **"Set temperature 0 for demo determinism" is now wrong advice.** On Claude Opus 4.7+ and Sonnet 5 a non-default value returns a 400. On OpenAI GPT-6 models with reasoning on, temperature must be removed. Anthropic says temperature 0 "never guaranteed identical outputs." Put it this way for teams: omit sampling params on current frontier models. For demo determinism, use cached or recorded fallback responses, fixed seed data, and low reasoning effort.
- **Step limits.** OpenAI Agents SDK defaults to 10 turns and raises `MaxTurnsExceeded`. Tell teams to catch it or use the `"max_turns"` error handler so the demo shows a graceful message. Vercel `ToolLoopAgent` defaults to 20 steps. `WorkflowAgent` has no limit, so teams must set `stopWhen` explicitly.
- **Caching.** Both vendors now price cache reads at around 0.1x or less, and both charge 1.25x for writes on newer models. At hackathon scale that only pays off if the same long prefix (system prompt, tools, docs) is reused within the TTL: 5 min on Anthropic by default, 30 min on OpenAI GPT-5.6+.
- **Helicone.** It still runs, but don't pick a maintenance-mode tool for a new project. Langfuse, now owned by ClickHouse, is still open source.
