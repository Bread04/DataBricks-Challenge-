## Verification of round-1 claims
- **"Current MCP spec is 2026-07-28"**: CONFIRMED by two sources (spec site plus the official blog, and SDK release notes on GitHub for TS and Python).
- **"Stateless, sessions removed"**: CONFIRMED. `Mcp-Session-Id` is removed and the `initialize` handshake is removed (changelog items 1–2).
- **"MCP Apps and Tasks formalized as extensions"**: CONFIRMED. Tasks moved from core to the `io.modelcontextprotocol/tasks` extension, and MCP Apps is listed as an extension. Extensions are opt-in and negotiated.
- **"Breaking for 2025-11-25 servers"**: PARTLY TRUE, needs nuance. The wire protocol does break: there is no initialize, no sessions, and server-to-client requests are replaced by MRTR, so a 2026-07-28-only client and a 2025-11-25-only server cannot interoperate naively. But there is backward compatibility:
  - `server/discover` works as a version and compat probe.
  - Clients must treat results without `resultType` as complete.
  - The Python SDK v2 supports "both 2025 and 2026-07-28 protocol eras".
  - The TS client v2 handles legacy servers.
  - Deprecated features keep working for at least 12 months.

  Suggested wording for the guide: "the new spec changes the wire protocol, but official SDK v2 clients still talk to older servers. The real migration pain is for servers that relied on session IDs or server-initiated sampling/elicitation."
- **"Anthropic MCP connector still beta header `mcp-client-2025-11-20`"**: CONFIRMED (docs frontmatter `betaHeader: mcp-client-2025-11-20`, status beta).
- **"A2A under Linux Foundation with 150+ orgs"**: The Linux Foundation part is CONFIRMED. The "150+ orgs" figure was NOT verified: the homepage gives no count and only names 8 TSC members. Drop the number or verify it from the partners page.

## Notes for synthesis
- For beginners: the fastest route to giving an agent tools is a hosted API connector (Anthropic `mcp_toolset` or OpenAI `type:"mcp"`) pointed at a public remote MCP server. Neither supports local STDIO servers. Anthropic's connector only exposes tools, not resources or prompts.
- If building an MCP server at a hackathon, use the Python SDK v2 (stable, `MCPServer`) or TS SDK v2 (`@modelcontextprotocol/server`). Old tutorials that use `FastMCP` or `@modelcontextprotocol/sdk` and session IDs are now out of date.
- The spec now recommends deterministic ordering for `tools/list`, which helps prompt-cache hits. That is worth a one-line tip.
- Computer use: Anthropic's tool is GA as `computer_toolset_20260801`. The old `computer_20251124` fails on Opus 5.5 on the Claude API, which is a likely beginner trap when following older tutorials.
- Browserbase's free tier (1 browser hour, 15-minute sessions) is enough for a demo but tight across a whole hackathon. Budget for the $20 plan or run Playwright locally.
- Security: cite Invariant (2025-04-01) for tool poisoning, OpenAI's exfiltration warning, and Anthropic's own prompt-injection guidance (use a VM, allowlist domains, have a human confirm).
- Dates on three GitHub release pages (Python SDK, Stagehand, Browser Use) came back from the summariser as 2024, which contradicts their content. Re-check them before printing exact dates.
