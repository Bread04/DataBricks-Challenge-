## Notes for synthesis
- **Tailwind/Shopify:** tell beginners there is no action needed. Tailwind CSS stays MIT, and the same team keeps maintaining it. Paid Tailwind Plus is closed to new buyers, so don't recommend buying it. No roadmap was announced.
- **2026 default stack (all versions checked on npm this run, most also on GitHub):** TanStack Query 5.103, Zustand 5.0, React Hook Form 7.88 + @hookform/resolvers 5.9, TanStack Form 1.33 (stable), Zod 4.6, Motion 13.4. For beginners, RHF + zodResolver is still the path with the most tutorials. TanStack Form v1 is stable and a fine alternative. Zod v4 compatibility for either library was NOT verified in docs this run. That resolvers 5.x and Zod 4.x are current together suggests support, but it is an inference.
- **Motion:** one-line a11y tip is to wrap the app in `<MotionConfig reducedMotion="user">`.
- **Free tiers are tight for a 24–48h event:** v0 gives 7 messages/day, Lovable 5 credits/day, Bolt 300K tokens/day, and Figma 500 credits/month (a single Make generation can use more than 100). Tell teams to spread their prompts across tools, or have each teammate use their own account.
- **Accessibility quick win:** add `@axe-core/playwright` 4.13 to a smoke test. Lighthouse CI has had no release since June 2025. The Lighthouse panel in Chrome DevTools is the easier option for a hackathon (not re-verified this run).
- **EAA short answer:** it covers specific products and services *placed on the market / provided to consumers* (e-commerce, banking, and similar). A hackathon prototype that is not offered commercially is outside practical scope, and services run by microenterprises are exempt under Art. 4(5). Accessibility still helps with judges and users. The "not placed on the market" reading is my inference from the scope wording, not a quoted text.
