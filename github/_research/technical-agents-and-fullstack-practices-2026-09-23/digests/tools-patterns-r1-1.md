## Notes for synthesis
- **The three vendors now agree on tool calling.** All offer strict/validated schemas (Anthropic `strict`, OpenAI `strict` on by default in Responses, Gemini `VALIDATED`), parallel calls with a switch to turn them off, forced or none tool choice, and deferred tool loading via tool search (Anthropic and OpenAI). Hackathon rule: **turn on strict mode, keep under about 20 tools (OpenAI) / "fewer, thoughtful tools" (Anthropic), and use tool search only if you really have dozens.**
- **Easiest path for beginners:** server-side tools (web search, code execution) need no code to run them. Use SDK loop helpers (Anthropic Tool Runner, OpenAI Agents SDK / Responses, Gemini automatic function calling) instead of writing the loop by hand.
- **Do/don't rules with evidence behind them:** namespace tool names; use unambiguous parameter names; write descriptions as if for a new teammate; return concise, readable output (no UUIDs); paginate and truncate; make errors actionable; use enums or poka-yoke arguments; don't wrap every API endpoint as its own tool.
- **Patterns:** give beginners a ladder: single call, then prompt chain or router, then parallelization, then evaluator-optimizer, then an agent loop. Anthropic's "start simple" (2024-12) still holds, and the 2025 context-engineering post builds on it rather than replacing it.
- **Multi-agent:** Anthropic and Cognition agree on where it fails: shared context, interdependent tasks, and coding. So for a 24–48h hackathon: **one agent loop by default**. Use parallel subagents only for read-only, independent research or fan-out. Budget roughly 15x tokens.
- **MCP:** the spec changed a lot on 2026-07-28 (stateless, breaking). Tell teams to use current Tier 1 SDKs and follow 2026 tutorials; 2025 tutorials may use sessions or SSE. The Anthropic MCP connector is still beta-headered (`mcp-client-2025-11-20`). MCP Apps now exists as a formal extension.
- **Security rules for the guide:** don't install random local MCP servers; read the launch command; avoid the lethal trifecta in demos; require human approval for writes, payments and sends; sandbox computer use.
- **Computer use:** both Anthropic (stable toolset 2026-08-01) and OpenAI (GA) now ship it, but I found no primary reliability numbers. Suggest it only as a stretch goal and prefer APIs or MCP when they exist.
- **A2A:** governed by the Linux Foundation and being adopted by enterprises. For a beginner hackathon it is almost certainly not worth the effort (my inference, not a sourced claim).
