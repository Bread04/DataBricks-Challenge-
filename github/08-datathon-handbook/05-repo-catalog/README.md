## 🧠 6. What Past Winning Repos Reveal (Common Patterns)

Analyzing repositories from 1st-place datathon winners reveals 5 clear habits:

1. **They Start with Questions, Not Algorithms:**
   Winning repos almost always have a section in their README outlining 3–5 hypotheses about the domain before any modeling code appears.
2. **They Save Out-of-Fold (OOF) Predictions:**
   They never evaluate on training data; they always log K-Fold out-of-fold validation scores so their numbers are 100% trustworthy.
3. **They Package an Interactive Frontend:**
   Winners frequently include a `streamlit_app.py` or web demo directory. It transforms an abstract math problem into an operational product judges can touch.
4. **They Include the Pitch Deck / Report PDF Directly in the Repo:**
   A folder called `presentation/` or `report/` containing the final 10-slide PDF is standard in top-tier submissions (such as Citadel Data Open).
5. **They Keep Code Clean & Self-Contained:**
   They provide a `requirements.txt` or `pyproject.toml` and a single script (like `run.py` or our `quickstart-1-click.py`) so anyone can replicate their results in 1 command.
