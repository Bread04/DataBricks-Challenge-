## Run 1 · toolkit standards (2026-09-21): AI model selection, prompting and RAG

Full report: [`technical-hackathon-toolkit-2026-09-21/research.md`](../../_research/technical-hackathon-toolkit-2026-09-21/research.md)

- **Anthropic prices (per MTok):** Sonnet 5 $2/$10 (the planned rise to $3/$15 was cancelled), Opus 5 $5/$25, Haiku 4.5 $1/$5, Fable 5.1 $10/$50. Cache reads cost 0.1× and Batch is 50% off. Tokenizers on 4.7+ produce about 30% more tokens [T34].
- **Other providers:**
  - OpenAI GPT-5.6 Terra $2/$12, Luna $0.20/$1.20; text-embedding-3-small $0.02 [T35]. Medium confidence: read through a summariser.
  - Gemini 3.8 Flash $0.75/$3.75, time-limited to 2026-12-31; the free tier trains on your data [T36].
  - Voyage embeddings from $0.02 with 200M free tokens [T37].
- **Prompting:**
  - Anthropic: XML-tagged sections, 3–5 examples, long documents first and the query last. **Prefill returns a 400 from 4.6 onward**, so use structured outputs or tools. `effort` replaces `budget_tokens` [T38].
  - OpenAI: developer message ordered Identity → Instructions → Examples → Context [T39].
- **RAG:**
  - Contextual Retrieval prepends 50–100 tokens of context to ~800-token chunks. Combined with hybrid BM25 and reranking, it cut retrieval failures by 67% [T40]. That figure is from a single vendor source and is 2 years old, so medium confidence.
  - Supabase recommends HNSW as the default index and does hybrid search through RRF with k=50 [T41][T42].
  - Vector-store free tiers come only from third-party pages [T55] (low confidence).
- **Repos [T54]:**
  - Current: vercel/ai; vercel/chatbot; anthropics/claude-cookbooks (plural name).
  - Stale: create-llama (last push 2025-07).
  - Moved: Ragas is now vibrantlabsai/ragas (last push 2026-02).

## Run 1 · toolkit standards (2026-09-21): Voice and realtime AI

Full report: [`technical-hackathon-toolkit-2026-09-21/research.md`](../../_research/technical-hackathon-toolkit-2026-09-21/research.md)

*Deepen 2026-09-22.*

- **Speech-to-speech APIs:**
  - OpenAI `gpt-realtime` is generally available (snapshot 2025-08-28). It takes audio and text over WebRTC, WebSocket or SIP. Audio costs $32 input / $64 output per 1M tokens, and $0.40 for cached input [T69].
  - Google names Gemini 3.8 Live as its current realtime voice model and calls the older Live previews legacy [T70] (medium confidence, search snippet).
  - **No public Anthropic realtime speech-to-speech API was found.** Claude's voice mode is a consumer and Claude Code feature (absence of evidence).
- **Cascaded pipeline** (for using Claude as the brain):
  - Deepgram gives $200 of free credit with no card. Streaming STT costs $0.0048–$0.0078/min and Aura-1 TTS costs $0.015 per 1K characters [T71].
  - ElevenLabs Flash TTS costs $0.05 per 1K characters (~75 ms) and Scribe v2 Realtime STT costs $0.39/hr. The free quota isn't stated [T72].
  - Kokoro-82M is an Apache-licensed offline TTS model (repo last pushed 2025-08) [T101].
- **Frameworks:** LiveKit Agents (14.3k stars) and Pipecat (15.8k) are both pushed daily [T101]. Vocode was last pushed 2024-11, so it is stale [T101]. Hosted Vapi and Retell each give about $10 of trial credit (low confidence, third-party sources).
- **Browser gotcha:** `getUserMedia` needs a secure context (HTTPS or localhost). An iframe needs `allow="microphone"`, and a denied or insecure page throws `NotAllowedError` [T73].

**Deprecations and consolidations.**

- OpenAI Assistants API: shut down 2026-08-26. Migrate to Responses + Conversations [A6].
- OpenAI Agent Builder: discontinuation announced 2026-06-03 [A6]. The Nov-30 shutdown date comes from a search snippet only (medium confidence).
- OpenAI launched a managed **Agents API** public beta on 2026-09-10 [A6].

**What each is best for.**

- **Claude Agent SDK** is "Claude Code as a library": file, bash and web tools, subagents, skills and hooks. It suits agents that edit files or run code [A2].
- **AI SDK v7's `ToolLoopAgent`** stops after 20 steps by default [A8]. `WorkflowAgent` has no limit [A8]. It also has a `HarnessAgent` that can run Claude Code or Codex [A8].
- **LangChain v1 `create_agent`** runs on the LangGraph runtime and is customised through middleware [A12].

**Practitioner sentiment (medium confidence, anecdotal).**

- One HN team is happy with LangGraph [A24].
- "Coding agents have replaced every framework I used" got 375 points (2026-02) [A24].
- The rule of thumb "if the control flow fits in about 5 bullets, you don't need a framework" appears in several independent blogs (medium confidence; not in the appendix).
- The old "abstraction overhead" complaint against LangChain is only partly addressed by v1 [A12][A24].

**Selection matrix.**

## Run 3 · agents & fullstack practices (2026-09-23): Tools, MCP & workflow patterns

Full report: [`technical-agents-and-fullstack-practices-2026-09-23/research.md`](../../_research/technical-agents-and-fullstack-practices-2026-09-23/research.md)

**Tool calling has converged across vendors.**

- Strict schemas: Anthropic `strict: true` [A27], OpenAI strict by default in the Responses API [A28], Gemini `VALIDATED` mode [A29].
- Parallel calls are on by default, with a switch to disable them [A26][A28].
- Tool search / deferred loading for large tool sets [A27][A28].
- Server-side tools (web search, web fetch, code execution) need no execution code on your side and no beta header on Claude [A27].

**Tool design rules (primary sources):**

- Use fewer, well-chosen tools, not one per API endpoint [A30]. OpenAI suggests fewer than 20 at the start of a turn [A28] (medium confidence).
- Namespace names (`asana_projects_search`) and use unambiguous parameter names [A30].
- Return concise, readable output: paginate and truncate, and don't return UUIDs. Claude Code caps tool output at 25k tokens [A30].
- Make error messages actionable [A30].
- Use enums or poka-yoke arguments so invalid calls are hard to make [A28][A31].

**MCP (two sources).**

- The current spec is **2026-07-28 (final)** [A35][A36]. It is stateless: `Mcp-Session-Id` and the `initialize` handshake are gone. `server/discover` is new and mandatory. Tasks and MCP Apps are now extensions [A37].
- Roots, Sampling, Logging and HTTP+SSE are deprecated but keep working for at least 12 months [A37].
- **"It breaks old servers" is only partly true.** SDK v2 clients still talk to 2025-era servers [A38][A39].
- SDK status: Python SDK v2 is stable (`FastMCP` renamed `MCPServer`) [A39]. TypeScript SDK v2 (`@modelcontextprotocol/server`, `@modelcontextprotocol/client`) was a beta on 2026-07-27, and its stability now is unconfirmed [A38].
- The fastest beginner path is a hosted connector:
  - Anthropic `mcp_toolset`: beta `mcp-client-2025-11-20`, tools only, remote HTTP only [A40].
  - OpenAI `type:"mcp"`: `require_approval` defaults to `"always"` [A41].

**MCP and agent security.**

- Tool poisoning hides instructions in tool descriptions [A43].
- The official best practices [A42]:
  - no token passthrough
  - block SSRF to private IPs
  - show the exact command before launching a local server
  - request minimal scopes
- The spec says tool annotations are untrusted unless the server is trusted [A35].
- OpenAI warns that a malicious server can exfiltrate anything in the model's context [A41].
- Tie these together with the **lethal trifecta** [A62]. Never combine these three in one agent:
  - private data
  - untrusted content
  - a way to send data out

**Computer and browser use.**

- Anthropic `computer_toolset_20260801` is GA. Opus 5.5 rejects the old `computer_20251124` [A44], which is a trap in older tutorials.
- OpenAI computer use is GA and recommends code execution (Playwright) over the structured tool [A45]. The model names in its docs are medium confidence.
- Browserbase free tier: 1 browser-hour, 15-minute sessions [A46]. Stagehand is at 3.7.3 [A47].
- No benchmark numbers were verified. Treat computer use as a stretch goal and prefer an API or MCP when one exists.

**A2A** is under the Linux Foundation and at v1.0 [A48]. The "150+ organisations" figure is unverified. It is not worth a beginner hackathon team's time (inference).

**Patterns.**

- **The ladder:** single call + retrieval → prompt chaining → routing → parallelisation → orchestrator-workers → evaluator-optimizer → autonomous agent [A31]. Use workflows when the path is predictable, and agents only when the number of steps can't be known in advance [A31].
- **Frameworks:** they can hide prompts, so understand the code underneath [A31].
- **Multi-agent:** Anthropic reports a 90.2% gain on its internal research eval [A32] (single vendor source, medium confidence). It costs about 15× chat tokens [A32] and fails on shared context and coding [A32][A33]. **Default to one agent. Use subagents only for independent, read-only fan-out.**
- **Context engineering:** use compaction, structured notes, just-in-time retrieval, and subagents that return summaries of about 1–2k tokens [A34].
- **Human in the loop:** OpenAI's MCP tool asks for approval by default [A41], and AI SDK v7 has `toolApproval` [A9]. Require approval for writes, payments and messages sent on the user's behalf [A42][A45].

## Run 3 · agents & fullstack practices (2026-09-23): Memory, evals, observability, reliability & demo-proofing

Full report: [`technical-agents-and-fullstack-practices-2026-09-23/research.md`](../../_research/technical-agents-and-fullstack-practices-2026-09-23/research.md)

**Memory ($0 options).**

- Keep the conversation in your own app state.
- OpenAI Agents SDK Sessions (`SQLiteSession`). Don't mix them with server-managed conversations in the same run [A56].
- Anthropic memory tool (`memory_20250818`, client-side, all Claude 4+ models) [A55]. Block path traversal and cap file sizes [A55].
- Mem0's free tier is 1k retrievals a month (single source).
- Letta and Zep were not researched.

**Observability and tracing free tiers.**

| Tool | Free tier | Notes |
| --- | --- | --- |
| **Langfuse** | 50k units/mo, 2 users, 30 days [A49] | OSS, self-hostable. Acquired by ClickHouse 2026-01-16 and stays OSS (two sources) [A50][A51] |
| LangSmith | 5k traces/mo, 1 seat, 14 days [A52] | seat limit hurts teams |
| Braintrust | 1 GB/mo, unlimited users, 14 days [A53] | |
| Helicone | — | acquired by Mintlify 2026-03-03, **maintenance mode**: don't start new projects on it [A54] |

The OpenTelemetry GenAI conventions moved to their own repo, and their stability is unconfirmed. Phoenix and Weave were not researched.

**Evals in 24–48 hours.**

- Start with 20–50 tasks drawn from real failures, and grade outcomes, not tool-call paths [A64].
- Use binary pass/fail, and read at least 30 traces [A65].
- Validate any LLM judge against your own labels [A64][A65].
- Generic metrics "create false confidence" [A65].
- Run multiple trials, because agents are nondeterministic [A64].

**Reliability: settings to use.**

| Risk | Rule | Evidence |
| --- | --- | --- |
| Runaway loop | Always set the cap yourself: OpenAI `max_turns` (default 10, raises `MaxTurnsExceeded`, can be caught with a `"max_turns"` handler); AI SDK `stopWhen` (`ToolLoopAgent` default 20; `WorkflowAgent` has none); Anthropic tool runner `max_iterations` | [A57][A56][A8][A55] |
| 429 / 529 | The SDKs retry twice with backoff [A58]. A **spend-cap 429 never recovers**, so a spend cap works as a budget kill-switch [A58] | [A58] |
| Serverless timeout | Vercel Hobby functions stop at **300 s including streaming** (504), with a 4.5 MB body limit [A61]. Split long runs into steps or move them to Vercel Workflows (GA) [A86] | [A61][A86] |
| Cost | Put stable system prompts and tools first so they get cached. Anthropic cache reads cost 0.1× (0.05× on Opus 5.5), with a 5-minute default TTL; the 1-hour TTL write costs 2× [A59]. OpenAI caching is automatic: reads 0.1×, 30-minute retention on GPT-5.6+ [A60] | [A59][A60] |
| Nondeterminism | **Don't set temperature.** Non-default values return 400 on Claude Opus 4.7+ and Sonnet 5, and temperature 0 "never guaranteed identical outputs" [A66]. GPT-6 models with reasoning also reject it [A67] | [A66][A67] |
| Long requests | Stream. The SDKs refuse non-streaming requests expected to run past 10 minutes [A58] | [A58] |

**Security.** The lethal trifecta [A62] and the OWASP Top 10 for Agentic Applications 2026 (published 2025-12-09, ASI01–ASI10; list taken from a summary, medium confidence) [A63].

**Demo-proofing.**

- Devpost advises recording a backup video early, because uploads can take hours [A68] (medium confidence).
- JetBrains' judges say: show something working within about 90 seconds, keep to one flow, and "mock everything you can" [A69].
- MLH's organiser guide treats venue Wi-Fi as a risk [MLH organiser guide; low-medium, not in the appendix].
- Since sampling parameters are out (see above), make the demo reliable with **golden or cached responses, seeded data, and a recorded fallback**.
